# RayChess

A chess game built with C++ and raylib to practice OOP, software design, Git, and building a project from scratch.

## Goals

* Build a complete project from scratch.
* Learn to use a third-party library through its documentation.
* Practice C++ and OOP.
* Improve Git and GitHub workflow.
* Practice breaking problems into smaller, manageable tasks.

## Status

🚧 In development

## Tech Stack

* C++
* raylib
* Git / GitHub
